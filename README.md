# 💰 Desafio dos R$ 125.250 — Sistema de Metas Financeiras

Uma aplicação web moderna, responsiva, fluida e visualmente elegante para gerenciar o famoso desafio dos **R$ 125.250,00** (guardando valores de **R$ 1 a R$ 500**).

> Baseado no princípio matemático da soma de Gauss: $\frac{500 \times 501}{2} = 125.250$

---

## ✨ Funcionalidades

- 📊 **Dashboard Financeiro em Tempo Real**: Exibe o total acumulado, total restante, média por depósito, percentual concluído e barra de progresso.
- 🎯 **Grade Interativa dos 500 Números**: Marque e desmarque valores de forma tátil, com efeitos visuais e sonoros suaves.
- 📅 **Previsão de Término Dinâmica**: Calcule a data de conclusão exata com base na sua frequência de depósitos (diário, 5x/semana, 3x/semana, etc.).
- 🎲 **Sorteador do Dia**: Deixe a sorte escolher qual valor guardar hoje, filtrando por intensidade (leves, moderados ou ousados).
- 🔍 **Filtros e Busca Instantânea**: Filtre por status (*Todos*, *Pendentes*, *Guardados*), faixas de valores (*1-100*, *101-200*, etc.) ou busque qualquer número específico.
- 💾 **Salvamento Automático & Backup**: Todos os dados são salvos no `LocalStorage` do navegador, com opção de exportar/importar arquivos `.json`.
- 🖨️ **Modo Impressão**: Layout especial e limpo para quem deseja imprimir a folha de controle física em papel.
- 🎉 **Marcos com Confetes**: Celebração com confetes e sons a cada marco conquistado (10%, 25%, 50%, 75% e 100%).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3 Moderno**: Design system com paleta *Emerald Luxury*, Glassmorphism, CSS Grid e Flexbox, 100% responsivo.
- **JavaScript (Vanilla)**: Lógica reativa, sintetizador de som nativo (*Web Audio API*) e confetes em *Canvas 2D*, sem nenhuma dependência externa pesada.

## 🚀 Como Executar Localmente

Como o projeto foi desenvolvido em tecnologias web puras, basta abrir o arquivo `index.html` em qualquer navegador:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ocJew/125.250.git
   ```
2. Abra a pasta do projeto:
   ```bash
   cd 125.250
   ```
3. Abra o arquivo `index.html` no seu navegador favorito (ou use qualquer servidor estático como Live Server, Python `python -m http.server`, etc.).
